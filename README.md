# Helseplan 2025 💚

Personlig helsetracking-app for kosttilskudd, mobilitet og vaner.

## Funksjoner

- 💊 Daglig tilskudd-tracking (morgen/lunsj/kveld)
- 🧘 Mobilitetsrutiner og treningsøkter
- 🍺 Alkohol-fri uke-tracking
- ⏱️ Bevegelsespause-timer (45 min)
- 📱 PWA - installer som app
- ☁️ Valgfri skysynkronisering mellom enheter

## Deploy til GitHub Pages

1. Opprett nytt **public** repo på GitHub
2. Last opp filene eller push med git
3. Aktiver **GitHub Pages** i Settings → Pages → Deploy from main branch
4. Appen er live på `https://DITT-BRUKERNAVN.github.io/helseplan/`

## Teknologi

- React 18 (via CDN)
- Vanilla CSS
- LocalStorage + JSONBin.io (valgfri backup)
- Service Worker (offline-støtte)
